# Byte Core 0.1.0

Byte Core 0.1.0 is the planned first functional self-managed release. This note is included now only to make candidate artifacts reproducible; it does not announce a release or authorize a tag.

The candidate contains the dependency-light lifecycle CLI, canonical deployment templates, exact-plan install/update/removal proofs, optional Bash and Zsh integration, local-first Byte Care diagnostics, and repository-native Codex guidance.

Known limitations:

- support is limited to the host matrix recorded in `docs/support-matrix.md`;
- remote update discovery and automatic diagnostic reporting are unavailable;
- enterprise fleet management, multi-administrator policy, and paid features are outside v0.1;
- elevated installation and package-manager integration are not provided; and
- the release remains blocked until all automated and manual release-gate evidence passes.

The current implementation also has limits documented in the configuration, shell integration, Byte Care, and Codex integration contracts under `docs/`: the internal configuration resolver does not enforce workspace-path semantics, shell verification does not check permission-only or sourced-script drift, diagnostics report a fixed bootstrap version and use bounded issue deduplication, and live Codex hook behavior still needs manual evidence. Explicit Kubuntu 26.04 support and testing remain planned release work under [issue #36](https://github.com/kodiakdirus/byte-core/issues/36).

The advisory SessionStart hook also fails to emit its graceful fallback when `source` is an array or object. This known malformed-input defect must be addressed in the integration acceptance review; passing the current unit suite does not cover that case.
